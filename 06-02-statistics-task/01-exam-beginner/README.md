# 01 Exam - Beginner EF Statistics

## Tema

Egyszeru `StudentScore` entitason gyakoroljuk az EF Core aggregalo muveleteket.

## Feladat

Toltsd ki a `StudentScoreStatisticsService` metodusait.

## Megoldando metodusok

- `SumPointsAsync`: osszes pontszam `SumAsync` hasznalataval.
- `GetHighestPointAsync`: legmagasabb pontszam `MaxAsync` hasznalataval.
- `GetAveragePointAsync`: atlagpontszam `AverageAsync` hasznalataval.

```bash
dotnet run --project Exam/Tests
```
