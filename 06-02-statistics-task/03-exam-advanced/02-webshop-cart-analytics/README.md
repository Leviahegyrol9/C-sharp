# 02 Webshop Cart Analytics

## Feladat

Webshop rendelesi es kosarertek statisztikakat kell keszitened EF Core hasznalataval.

## Megoldando metodusok

- `CalculateNetRevenueAsync`: teljes netto bevetel rendeles tetelekbol es kedvezmenyekbol.
- `CalculateAverageCartValueAsync`: atlagos kosarertek rendelesenkent.
- `CalculateReturnedOrderPercentageAsync`: visszakuldott rendelesek aranya szazalekban.

## Ellenorzes

```bash
dotnet run --project Exam/Tests
```
