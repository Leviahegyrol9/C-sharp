# 01 Course Completion Analytics

## Feladat

Oktatasi riporthoz kell EF Core statisztikakat keszitened kurzusteljesitesi adatokbol.

## Megoldando metodusok

- `CalculateCompletionPercentageForDepartmentAsync`: tanszeki teljesitesi arany szazalekban.
- `CalculateAverageWatchMinutesPerStudentForRequiredCoursesAsync`: kotelezo kurzusokon atlagos tanulasi ido hallgatonkent.
- `CountRequiredCoursesBelowCompletionAsync`: adott kuszob alatti teljesitesi aranyu kotelezo kurzusok szama.

## Ellenorzes

```bash
dotnet run --project Exam/Tests
```
